# easycube-app.github.io

La page de confidentialité d'EasyCube, servie par GitHub Pages à l'adresse
<https://easycube-app.github.io/>. C'est cette adresse que demande le champ
**Privacy Policy URL** d'App Store Connect, obligatoire pour toute app, qu'elle
collecte quelque chose ou non — et qui doit être consultable **sans installer
l'app**, ce qu'un écran dans l'app ne peut pas être.

**Le même texte vit aussi dans l'app**, dans son écran Réglages → Confidentialité.
Deux copies d'un texte, ça dérive : si l'une change, changer l'autre. Le dépôt
du code en garde la source dans `EasyCube/docs/privacy/`, avec la note qui
explique pourquoi il y en a deux.

Le dépôt doit rester **public** : GitHub Pages en gratuit ne sert que ceux-là.
